# Wireless audit: defects and fixes (25 Nov 2026)

| Defect / Gap | Resolution | Verification |
|---|---|---|
| Production firmware forbade `TORQVA_WIFI_LINK` at compile time and allowed raw USB text bypasses. | Added `esp32s3_wireless`; removed unauthenticated raw USB bypass and backend `direct_mode` / `universal_mode`. | `pio run -e esp32s3_wireless`, `166/166` native tests, `794/794` backend tests pass. |
| Authorized motor control became unavailable after deleting `commissioning.py`. | Implemented `OperatingConfigManager` (`backend/torqva/device_config.py`) auto-loading hardware-safe ceilings, syncing with `PUT /limits`, and pushing `cfg` over the authenticated session without extra user interlock forms. | `test_operating_config_auto_loads_and_syncs_with_limits_manager`, `test_torqva_p16_serial.py`, `test_torqva_p21_legacy_retired.py` pass (`794/794`). |
| Docker source compilation was missing and failed on duplicate `lib_extra_dirs` / read-only `PLATFORMIO_CORE_DIR` when initially tested. | Fixed `compiler.py` INI generation, mapped `/tmp/pio` writable tmpfs with read-only symlinked `/opt/pio` toolchains + `/opt/pio_libs`, and pinned `espressif32@7.1.3`. | Built `torqva-pio:latest`; verified `.ino` compilation to `1,021,584 B` ESP32-S3 `.bin` in `79.0 s` under `--network none --read-only --cap-drop ALL`. |
| Missing engineering workspace UI, discovery, Wi-Fi management, wireless logs, manual rollback, and HTTP Range resumption. | Implemented `wirelessWorkspace.jsx`, `discovery.py`, `deployments.json`, HTTP `206` Range downloads in `firmware_routes.py` + `ota_esp32.cpp`, `rb=1` rollback, `sys`/`wifi_cfg` MAC commands, and mDNS (`_torqva._tcp.local`). | `285/285` Vitest tests, `vite build` (`11.10 s`), `794/794` backend tests pass. |
| `device/connect-ip` returned HTTP `422` for operator role instead of `403` because route lacked `Role.ADMIN`; `interlocks()` returned `"UNAVAILABLE"`/`"VERIFIED"` for hardware-only `estop`/`driver`/`watchdog`; `test_torqva_firmware.py` had a reader-thread race on duplicate counter assertion. | Aligned `/device/connect-ip` to `Role.ADMIN` (`test_torqva_feature_audit.py`), kept hardware items `NOT VERIFIED` (`serial_bridge.py`), and awaited reader frame processing (`test_torqva_firmware.py`). | Full `794` backend tests pass (`0` failed, `0` skipped). |
| Baseline backend run had `30` skipped tests due to unbuilt `fitl` and `esp32s3_uart` binaries. | Built `pio run -e fitl` and `pio run -e esp32s3_uart`. | All `30` previously skipped tests now run and pass (`0` skipped). |

Physical verification on `COM7` (CH343 ESP32-S3) with motor power disconnected remains pending explicit user confirmation before flashing.
