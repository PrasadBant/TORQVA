# Historical documents (retired)

These files describe earlier states of the project, mostly the retired `smart-motor-monitor` prototype (Arduino sketch, TCP `MOTOR_ON` / `MOTOR_OFF` commands, the old health-engine backend and dashboard). That code is no longer in the tree. The files are kept unchanged as a record; **none of them describes how TORQVA works today**, and no instruction in them should be followed.

| File | What it recorded |
|---|---|
| `ARCHITECTURE.md` | The original system roadmap and TCP motor-command flow |
| `DEVELOPMENT_PHASES.md` | The original 10-phase plan |
| `NEW_LAPTOP_SETUP_REPORT.md` | Setup of the legacy sketch toolchain |
| `PHASE_5_HEALTH_ENGINE_REPORT.md` | The legacy rule-based health engine |
| `PHASE_6_HARDWARE_VALIDATION_REPORT.md` | Bench validation of the legacy sketch |
| `PHASE_6_1_UI_ENHANCEMENT_REPORT.md` | The legacy dashboard's visual pass |
| `TORQVA_AUDIT.md` | The Phase 0 audit of the repository as it was found |

Current documentation is listed in [`../README.md`](../README.md).
