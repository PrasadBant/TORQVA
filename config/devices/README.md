# Device configuration

Set `TORQVA_DEVICE_PORT` for a fixed serial port and `TORQVA_AUTOCONNECT=0` to disable scans. Set `TORQVA_DEVICE_LINK=1` to enable device Wi-Fi admission. Provision and store per-device keys using the [provisioning tools](../../scripts/setup/) and `TORQVA_DEVICE_KEYS_FILE`. See the [Wi-Fi setup guide](../../docs/hardware/WIFI_SETUP_GUIDE.md) for TLS and board settings.
