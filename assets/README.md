# Project Assets & Media

This directory stores non-sensitive assets for the Smart Motor Condition Monitoring & Control project, including:
- Architectural diagrams
- Hardware wiring schematics
- UI screenshots & mockups
- Hardware component datasheets and reference media

---

## Folder Usage Rules
- **DO NOT** store sensitive credentials, passwords, API tokens, or `.env` files here.
- Maintain clean, descriptive file names (e.g., `wiring_diagram.png`, `dashboard_preview.png`).
